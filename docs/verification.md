## 720 px 慢网冷启动

条件：720×900 视口、禁用缓存、延迟 150 ms、下载限速 200,000 B/s、上传限速 100,000 B/s。

结果：

- 序厅可用，资源传输合计约 393 KB，包含响应头。
- 首屏未请求三维地图分块、地球纹理或 MP3 音乐。
- 进入路线后，三维路线正常加载。

该传输量属于本轮冷启动和限定网络配置，不代表所有设备、服务端压缩配置或缓存状态下的固定体积。本次未记录可作为结论的 LCP、INP 或完整加载耗时。

## 交互与失败降级

| 检查 | 结果 |
|---|---|
| 阻断 `earth-2k.webp`／`earth-4k.webp` | 地图纹理载入失败后自动切换静态站点导览。 |
| 静态导览逐站点亮十二站 | 关闭最后一站详情后进入终章。 |
| 刷新页面 | 序厅显示 12／12 的续览记录。 |
| 章节上一章／下一章 | 切换可用。 |
| 章节返回与焦点 | 返回及焦点恢复已检查。 |
| 本地预设问答 | 可用。 |
| 1920 px 站点标记与点击 | 修复后十二个 marker DOM 可见；点击瑞金 SVG 打开对应资料。 |
| 站点详情 Esc | 返回路线，焦点回到瑞金节点。 |
| 重走清空 | 从十二站存档进入设置并重走，首页无续览入口，路书显示 0／12。 |
| 声音默认状态 | 音效关、音乐关；未据此宣称音频播放已验证。 |
| 减少动态效果开关 | `aria` 状态与 `html.reduce-motion` 类同步，最后恢复默认关闭。 |
| 设置 Esc | 关闭设置，焦点返回设置按钮。 |

1920 px 检查发现地图标签被库内部旧相机视角判定隐藏。修复使用 `htmlElementVisibilityModifier` 交由已有逐帧背面判定管理标签，并关闭 `animateIn`；上述标记与点击结果为修复后的复核结果。

本轮临时网络限制与视口覆盖已恢复。纹理请求阻断验证了资源失败分支；本轮没有单独注入 GPU 上下文丢失，因此不将此结果等同于所有 WebGL 故障均已实机验证。
